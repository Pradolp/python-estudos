# Python do zero

Curso prático que cobre a **fase "Python do zero"** do roadmap *Do zero à primeira vaga em IA*.
Ao terminar as 14 aulas você terá marcado todas as tarefas dessa fase.

## Como estudar cada aula

Cada pasta `aulaXX` tem quatro arquivos:

| Arquivo        | Para que serve                                                        |
|----------------|-----------------------------------------------------------------------|
| `README.md`    | A teoria, explicada passo a passo. Leia primeiro.                     |
| `exemplos.py`  | Código comentado. Rode, leia a saída, mude valores e rode de novo.   |
| `exercicio.py` | Os exercícios. Escreva seu código onde está indicado.                 |
| `solucao.py`   | Uma solução possível. **Só abra depois de tentar de verdade.**        |

Para rodar um arquivo, abra o terminal do VS Code (`Ctrl + '`) na pasta `python` e digite:

```bash
python aula01/exemplos.py
```

> Dica: digite os exemplos à mão em vez de copiar e colar. Errar a digitação e ler a
> mensagem de erro faz parte do aprendizado.

## Instalação (primeira tarefa do roadmap)

1. **Python 3.12 ou mais novo.** Baixe em <https://www.python.org/downloads/>.
   No instalador do Windows, marque **"Add python.exe to PATH"**.
   Confira no terminal: `python --version` (este computador já tem o Python 3.13).
2. **VS Code.** Baixe em <https://code.visualstudio.com/>.
3. **Extensão Python** no VS Code: menu Extensões (`Ctrl + Shift + X`), procure "Python"
   (da Microsoft) e instale.
4. Abra esta pasta no VS Code: *File > Open Folder…*
